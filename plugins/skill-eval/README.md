# skill-eval

Правило (rule), которое напоминает агенту перед ответом:

1) сначала проверить доступные skills,
2) активировать подходящие,
3) и только потом отвечать/выполнять.

Содержимое:
- `.opencode/rules/00-skill-eval.md`

Если вы хотите более «жёсткое» поведение (хук на каждый промпт) — можно заменить rule на plugin и повеситься на `tui.prompt.append`.
