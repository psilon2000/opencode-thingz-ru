# review

Инструменты для ревью PR/issue и коротких технических комментариев.

Содержимое:
- `.opencode/skills/review_pr/SKILL.md` — ревью PR/issue (через `gh`), режимы Quick/Full.
- `.opencode/skills/review_writing_style/SKILL.md` — «стоп AI-воде», коротко и по делу.
- `.opencode/skills/review_git_review/SKILL.md` — аннотационное ревью диффа.
- `.opencode/scripts/git-review.py` — скрипт для аннотаций диффа (запускается в терминале).

Требования:
- GitHub CLI `gh` (для ревью PR/issue и постинга комментариев/ревью).
