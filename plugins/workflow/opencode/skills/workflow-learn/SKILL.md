# Learn: сохранить знания проекта в AGENTS.md

Цель: переносить из чата в репозиторий только то, что реально помогает дальше работать (конвенции, архитектура, нюансы деплоя).

## Процесс

1) Коротко выпиши 5–15 кандидатных пунктов «что стоит запомнить», например:
- архитектурные решения и причины,
- принятые соглашения (именования, структура папок),
- опасные места и как с ними работать,
- команды/рутины для разработки,
- тестовые правила, CI особенности.

2) Отфильтруй tactical детали:
- конкретный баг, который чинили,
- временный workaround,
- разовую правку.

3) Попроси пользователя выбрать, что сохранять (можно мультивыбор).
4) Открой/создай `AGENTS.md` в корне репозитория.
5) Добавь выбранные пункты в раздел **Project notes** (или создай его).
6) Не дублируй — если пункт уже есть, обнови/уточни, но не повторяй.

## Формат записи

- Короткие буллеты
- По возможности: «что» + «почему» + «пример/команда»
