# Markdown → clipboard

1) Приведи ответ к чистому markdown:
- без лишних заголовков первого уровня,
- с корректными списками и таблицами,
- код — только в fenced code block,
- без служебных пояснений вроде «скопировано ниже».

2) Если текст не markdown, сначала отформатируй его как аккуратный markdown.

3) Скопируй результат в буфер обмена:
- используй tool `clipboard`,
- если tool недоступен — выведи markdown без лишнего обрамления.

Важно: в буфер копируй **только** финальный markdown, без пояснений вокруг.
