# workflow

Набор «повседневных» навыков:

- `workflow-learn` — извлечь полезные знания из сессии и записать в `AGENTS.md`.
- `workflow-clarify` — разобрать непонимание: ожидание vs реальность + проверка кода.
- `workflow-wrong` — перезапуск подхода, когда «застряли».
- `workflow-md-copy` / `workflow-txt-copy` — копирование результата в буфер (через custom tool).

Содержимое:
- `.opencode/skills/...`
- `.opencode/tools/clipboard.ts` — custom tool для буфера обмена (pbcopy/wl-copy/xclip/xsel/clip).
