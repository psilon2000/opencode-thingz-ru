# workflow

Набор «повседневных» навыков:

- `workflow_learn` — извлечь полезные знания из сессии и записать в `AGENTS.md`.
- `workflow_clarify` — разобрать непонимание: ожидание vs реальность + проверка кода.
- `workflow_wrong` — перезапуск подхода, когда «застряли».
- `workflow_md_copy` / `workflow_txt_copy` — копирование результата в буфер (через custom tool).

Содержимое:
- `.opencode/skills/...`
- `.opencode/tools/clipboard.ts` — custom tool для буфера обмена (pbcopy/wl-copy/xclip/xsel/clip).
