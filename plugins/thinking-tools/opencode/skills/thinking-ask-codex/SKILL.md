# Ask Codex: второе мнение

Используй этот навык:

- когда пользователь явно просит «спросить codex»,
- когда после нескольких попыток расследования не осталось хороших идей,
- когда нужен дополнительный независимый review сложного изменения.

## Процесс

1) Сначала проверь, что `codex` доступен:

```bash
which codex
```

Если CLI не найден — честно скажи об этом и остановись.

2) Собери контекст кратко:
- в чём проблема,
- какие файлы и строки важны,
- что уже попробовали,
- какой именно вопрос нужно задать Codex.

3) Не подсовывай Codex целые файлы без необходимости.
   Достаточно дать пути и фокус-вопрос — он сам дочитает нужное.

4) Запусти `codex` в read-only режиме.
   Базовая форма:

```bash
codex exec -m gpt-5.4 --sandbox read-only "<сфокусированный запрос>"
```

5) Когда ответ получен:
- отдели фактический анализ от шума CLI,
- покажи пользователю краткое summary,
- добавь свою оценку: где согласен, где нет,
- **не применяй правки автоматически**.

## Формат результата

- Что спросили у Codex
- Что Codex считает корнем проблемы / главным риском
- Насколько это похоже на правду по коду
- Что предлагается сделать дальше

## Ограничение

Этот навык нужен для второго мнения. Он не заменяет нормальный анализ и не даёт разрешения автоматически менять код.
