# thinking-tools

Аналитические навыки:

- `thinking-dialectic` — аргументы «за» и «против» с итоговым синтезом.
- `thinking-root-cause` — поиск первопричины через «5 почему».
- `thinking-ask-codex` — получить второе мнение от `codex` CLI для сложного расследования или ревью.

Полезно для архитектурных решений, разборов инцидентов, системных багов.
