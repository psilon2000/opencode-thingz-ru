# Custom Rules for Brainstorm

Плагин `brainstorm` умеет подтягивать дополнительные правила для обсуждения дизайна и выбора подхода.

## Где искать правила

Проверка идёт в таком порядке:

1. `./.opencode/brainstorm-rules.md`
2. `~/.config/opencode/brainstorm-rules.md`

Если оба файла существуют и не пустые, используется проектный файл. Пустой файл считается отсутствующим.

## Как загружается

Плагин использует:

```bash
bash .opencode/scripts/brainstorm-resolve-rules.sh brainstorm-rules.md
```

Если нужен нестандартный global path, второй аргумент скрипта может явно указать каталог с rules-файлом.

## Как применять

- Правила влияют на предлагаемые подходы, ограничения, naming и критерии успеха.
- Они дополняют встроенные инструкции skill, а не заменяют их.

## Пример

```md
## Предпочтения
- сначала предлагай минимальный путь
- не предлагай больше 3 вариантов

## Совместимость
- всегда уточняй backward compatibility
- выделяй рискованные миграции отдельно
```
