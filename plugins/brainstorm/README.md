# brainstorm

Содержимое:
- `.opencode/skills/brainstorm-do/SKILL.md`
- `.opencode/commands/brainstorm.md` (удобная команда-обёртка)
- `.opencode/scripts/brainstorm-resolve-rules.sh` — загрузка project/global custom rules для brainstorm.
- `.opencode/references/brainstorm/custom-rules.md` — описание custom rules механики для OpenCode.
