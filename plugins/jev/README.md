# jev

Массовые типизированные решения через [Jev](https://docs.typesafe.ai/models) (TypeSafe): модель отвечает о каждом элементе вероятностью «да», выбором варианта или оценкой по шкале. Основная модель решает сложное и пишет текст, а однотипную разметку десятков и сотен элементов отдаёт Jev.

- `jev-ask` — навык: когда звать Jev (по просьбе «спроси у Jev» и самостоятельно, если нужно одно решение для многих элементов), какие данные можно отправлять, как формулировать вопрос и проверять порог.
- `scripts/jev_ask.py` — CLI без внешних зависимостей: элементы из файла или stdin (JSONL, JSON-массив или строки), пачки и параллельные запросы, фильтр чувствительных данных, сводка на stdout и результаты без текстов в JSONL.

Нужен ключ TypeSafe: переменная `TYPESAFE_API_KEY` или файл `~/.config/typesafe/api_key` (права 600). Данные уходят в TypeSafe (США); фильтр по умолчанию пропускает элементы с номерами карт, телефонами, ИНН, СНИЛС, паспортами, секретами и кадровыми темами.

Проверка без сети: `python3 opencode/scripts/jev_ask.py --test`.
