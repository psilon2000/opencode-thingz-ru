# planning

Шаблон для подготовки плана внедрения и его ревью.

Содержимое:
- `.opencode/commands/plan_make.md` — команда создания плана в `docs/plans/...`.
- `.opencode/skills/plan_review/SKILL.md` — авто-ревью качества плана (полнота, тесты, YAGNI).
- `.opencode/scripts/plan-annotate.py` — аннотирование плана через `$EDITOR` и вывод unified diff.
