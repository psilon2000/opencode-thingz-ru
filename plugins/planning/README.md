# planning

Шаблон для подготовки плана внедрения и его ревью.

Содержимое:
- `.opencode/commands/plan-make.md` — команда создания плана в `docs/plans/...`.
- `.opencode/skills/plan-review/SKILL.md` — авто-ревью качества плана (полнота, тесты, YAGNI).
- `.opencode/scripts/plan-annotate.py` — аннотирование плана через `$EDITOR` и вывод unified diff.
- `.opencode/scripts/planning-resolve-rules.sh` — загрузка project/global custom rules для planning.
- `.opencode/references/planning/custom-rules.md` — описание custom rules механики для OpenCode.
