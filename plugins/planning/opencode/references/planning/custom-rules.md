# Custom Rules for Planning

Плагин `planning` умеет подтягивать дополнительные project-specific правила поверх встроенного workflow.

## Где искать правила

Проверка идёт в таком порядке:

1. `./.opencode/planning-rules.md`
2. `~/.config/opencode/planning-rules.md`

Если оба файла существуют и не пустые, используется проектный файл. Пустой файл считается отсутствующим.

## Как загружается

Плагин использует:

```bash
bash .opencode/scripts/planning-resolve-rules.sh planning-rules.md
```

Если нужен нестандартный global path, второй аргумент скрипта может явно указать каталог с rules-файлом.

## Как применять

- `plan-make` использует правила как дополнительные ограничения при создании плана.
- `plan-review` использует те же правила как дополнительные критерии ревью.

Правила дополняют встроенные инструкции, а не заменяют их.

## Пример

```md
## Тестирование
- всегда добавляй негативные кейсы
- указывай конкретные команды проверки

## Декомпозиция
- каждая задача должна быть выполнима за 1-3 часа
- избегай задач вида "сделать весь модуль"
```
